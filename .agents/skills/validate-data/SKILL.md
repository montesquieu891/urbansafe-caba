# validate-data

- Recalcula cifras clave desde las fuentes o el dataset procesado. Comprueba filtros, denominadores, períodos parciales, claves y duplicación por joins. Reconcilia cifras entre notebook, tablas, figuras e informe.
- Comprueba que la evidencia respalde cada afirmación relevante y que se documenten faltantes y sesgos. Para hallazgos de modelado aplica la revisión científica especializada.
- Entrega un dictamen con evidencias, problemas reproducibles y condiciones para compartir o cerrar el hito.
